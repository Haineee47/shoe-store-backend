# 4. Data Ownership

  Module      Owned Data
  ----------- -------------------------------------------
  Identity    User, Role, Refresh Token
  Catalog     Brand, Category, Product, Product Variant
  Inventory   Stock, Stock History
  Cart        Cart, Cart Item
  Address     Address
  Promotion   Coupon
  Order       Order, Order Item
  Payment     Payment
  Shipping    Shipment
  Reporting   Read Models

Nguyên tắc:

-   Một dữ liệu chỉ có một Owner Module.
-   Không tồn tại đồng sở hữu dữ liệu.

# 6. State Ownership

  State Machine     Owner Module
  ----------------- --------------
  User Account      Identity
  Product           Catalog

  Order             Order
  Payment           Payment
  Shipment          Shipping
  Coupon            Promotion

Module khác không được thay đổi trực tiếp state thuộc owner module.

------------------------------------------------------------------------

# 7. Transaction Ownership

Nguyên tắc:

-   Transaction có đúng một orchestrator.
-   Module owner chịu trách nhiệm commit business state của chính mình.
-   Không có distributed transaction giữa các module trong Modular
    Monolith.

Checkout:

Order Module đóng vai trò orchestrator:

-   Validate Cart
-   Validate Address
-   Validate Coupon
-   Validate Inventory
-   Create Order
-   Trigger Payment flow theo policy

------------------------------------------------------------------------

# 8. Dependency Rules

Được phép:

``` text
Order → Inventory
Order → Promotion
Order → Payment
Order → Shipping
Cart → Catalog
Cart → Inventory
```

Không được phép:

``` text
Inventory → Order
Payment → Catalog
Shipping → Inventory
Promotion → Payment
```

Không được tạo circular dependency.

------------------------------------------------------------------------

# 9. Cross Module Communication

Các nguyên tắc:

-   Không truy cập Repository của module khác.
-   Không sửa Aggregate của module khác.
-   Không chia sẻ Entity giữa các module.
-   Chỉ giao tiếp qua Application boundary hoặc Port phù hợp.
-   Chỉ trao đổi dữ liệu tối thiểu cần thiết.
