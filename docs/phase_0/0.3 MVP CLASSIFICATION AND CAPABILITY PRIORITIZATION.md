# 9. Scope Freeze Rules

Sau khi đóng băng:

-   Không thêm capability mới vào MVP nếu chưa đánh giá dependency.
-   Không chuyển capability Future vào MVP chỉ vì "tiện làm".
-   Mọi thay đổi phạm vi phải có Change Request hoặc ADR nếu ảnh hưởng
    kiến trúc.
-   Không triển khai ngoài phạm vi MVP trước khi hoàn thành luồng bán
    hàng chính.
