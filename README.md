# Shoe Store Backend

Backend REST API for a production-oriented shoe store application.

## Technology Baseline

- Java 21
- Spring Boot 4.1.0
- Maven 3.9.16
- MySQL 8.4.5 LTS
- Spring Data JPA
- Flyway
- Spring Security
- JWT
- Docker
- Testcontainers

## Architecture

- Modular Monolith
- Layered Architecture
- Clean Architecture Principles
- DDD Lite

## Project Status

Phase 1 — Project Bootstrap & Development Foundation.
